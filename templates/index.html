Kyle Mulleady

Full-stack engineer. Former React devotee, now htmx convert.

I spent about a decade building single-page applications. I had strong opinions about state management. I had a folder named reducers and I would have defended it in front of a jury.

Then I tried htmx, deleted most of my JavaScript, and everything got faster. There is no dignified way to report that result, so I have stopped trying to find one. Consider this my conversion narrative. The sacrament is hx-post. The heresy is a 400 kilobyte bundle that renders a table.

This site is the logical conclusion. Markdown files, Jinja templates, and a build script that finishes before you can tab away. It ships zero JavaScript and will still render correctly in 2040, which is more than I can say for anything else I wrote in 2016.
